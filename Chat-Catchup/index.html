User

How do I code this?

Assistant

In Unity, create a C# script named SciFiRoomLight and attach it to an empty GameObject. Drag the room's main Light into the Main Light field in the Inspector. Use the arrow keys in the desktop preview to rotate the light and compare the highlight and shadow.

using UnityEngine;

public class SciFiRoomLight : MonoBehaviour
{
    [SerializeField] private Light mainLight;
    [SerializeField] private float rotationSpeed = 35f;

    private void Start()
    {
        mainLight.type = LightType.Directional;
        mainLight.intensity = 1.2f;
        mainLight.shadows = LightShadows.Soft;
    }

    private void Update()
    {
        float horizontal = Input.GetAxis("Horizontal");
        float vertical = Input.GetAxis("Vertical");
        transform.Rotate(Vector3.up, horizontal * rotationSpeed * Time.deltaTime);
        transform.Rotate(Vector3.right, -vertical * rotationSpeed * Time.deltaTime);
    }
}

Create a Directional Light, assign it to the script, press Play, and use the arrow keys. Test on Meta Quest later when the headset is available.
